# MentorForge AI

Локальная обучающая платформа для подготовки к собеседованиям backend / AI engineer.

Проект помогает последовательно изучать Go, Python, SQL, Backend, AI/ML и System Design через лекции, самостоятельные ответы, сравнение с эталоном и практические задания. Сервер написан на Go с использованием стандартных `net/http` и `html/template`. Учебные данные хранятся в памяти приложения, а результаты пользователя — только в браузере.

## Как запустить

Команды выполняются из каталога `mentorforge-ai/backend-go`.

```bash
make run
```

Если команда `make` недоступна в текущем терминале Windows, приложение можно запустить напрямую:

```bash
go run ./cmd/api
```

После запуска откройте `http://localhost:8080`.

## Как запустить тесты

```bash
make test
```

Альтернативная команда без `make`:

```bash
go test ./...
```

## Учебный процесс

Один урок проходится строго по этапам:

1. Прочитать полноценную лекцию.
2. Нажать «Я прочитал лекцию — перейти к вопросам».
3. Ответить на контрольные вопросы своими словами и зафиксировать ответы.
4. Сравнить собственные ответы с кратким эталоном и ответом для собеседования.
5. Выполнить отдельное практическое задание.
6. Сохранить черновик или завершить практику.
7. Открыть страницу завершения и скачать Markdown-файл.
8. Передать файл наставнику для независимой проверки.

Эталонные ответы скрыты до фиксации собственного ответа. Практика открывается после прочтения лекции и фиксации всех обязательных ответов.

## Веб-интерфейс

- `GET /` — главная страница с темами и экспортом всех результатов;
- `GET /topics/{id}` — уроки выбранной темы и экспорт результатов темы;
- `GET /learn` — совместимая ссылка на первую лекцию;
- `GET /learn/{questionID}` — совместимая ссылка на лекцию, к которой относится вопрос;
- `GET /progress` — техническая карта карьерного прогресса;
- `GET /lessons/{id}` — полноценная лекция;
- `GET /lessons/{id}/questions` — контрольные вопросы урока;
- `GET /lessons/{id}/practice` — условие и форма практического задания;
- `GET /lessons/{id}/complete` — состояние урока, сброс и экспорт результатов.

HTML-интерфейс использует обычные HTML, CSS и JavaScript без frontend-фреймворков, внешних CDN и сборщиков.

## Career Progress

Страница `GET /progress` показывает пять основных шкал: Go Engineer, Python Engineer, Backend / Architecture, AI Engineer и Job Readiness. По Job Readiness определяется текущая Career Stage и расстояние до следующего этапа. На той же странице отдельно показаны Job Search roadmap, следующий конкретный objective и AI Journey к собственному MentorForge Agent.

Проценты являются рабочей оценкой наставника MentorForge, основанной на выполненных учебных задачах и текущих инженерных навыках. Это не отраслевой сертификат. Фактическое завершение Lessons читается отдельно из browser `localStorage` и не используется как автоматическая формула карьерной готовности.

Ориентир для начала первых системных откликов — примерно 60% Job Readiness; 100% не требуется для старта и 60% не гарантирует получение работы.

## Первый полноценный урок

Урок «Что такое программа и язык Go» объясняет:

- программу и исходный код;
- язык программирования и Go;
- компиляцию и исполняемый файл;
- `package main`, `import`, `func main` и `fmt.Println`;
- запуск программы командой `go run main.go`.

После лекции доступны пять контрольных вопросов и отдельное задание: написать нейтральную Go-программу с тремя строками учебного представления. Готовое итоговое решение в условие не включено.

## Урок 3: условия, циклы и коллекции Go

Третий урок темы Go Basics продолжает материал о типах, структурах, функциях и ошибках. В нём изучаются:

- логический тип `bool`, сравнения, `if`, `else if` и `else`;
- три базовые формы цикла `for`, а также `break` и `continue`;
- различие массива и slice;
- `len`, `cap`, `append` и безопасная работа с индексами;
- обход slice через `range`;
- пары ключ-значение в `map`;
- безопасный поиск через `value, ok`;
- отсутствие гарантированного порядка обхода `map`;
- различия nil и пустых коллекций на начальном уровне.

Урок проходится в общем порядке: сначала лекция, затем девять самостоятельных ответов, сравнение с эталоном, практика и страница завершения.

Практика «Каталог учебных карточек» предлагает самостоятельно создать консольную Go-программу со slice карточек, фильтрацией по минимальному уровню, map-индексом и безопасным поиском. В материале есть структура `StudyCard`, рекомендуемые сигнатуры и поэтапные подсказки, но нет готовой реализации функций или полного решения.

При выполнении нужно проверить как успешные, так и ошибочные сценарии. В поле «Результат запуска» следует вставить полный фактический вывод программы, включая корректный поиск, некорректный уровень, пустое название и отсутствующий ключ.

После завершения урока файл `mentorforge_submission_go_lesson_03.md` скачивается кнопкой «Скачать результаты урока». В него попадают собственные ответы, решение и полный вывод пользователя; лекция, эталоны и подсказки не экспортируются.

## Локальное хранение результатов

База данных пока не используется. Браузер сохраняет:

- прочтение лекции — `mentorforge.lesson.read.{lessonID}`;
- ответ на вопрос — `mentorforge.question.answer.{questionID}`;
- практическое решение — `mentorforge.practice.submission.{practiceTaskID}`.

Для каждого ответа хранятся текст, ISO-дата изменения и признак фиксации. Практическая запись содержит решение, объяснение, результат запуска, сложности, отметки самопроверки, самооценку и необязательные поля GitHub.

Старые ответы из ключей `mentorforge.answer.{questionID}` читаются и переносятся в новый формат. После обновления страницы черновики восстанавливаются. Данные не отправляются на сервер или во внешние сервисы.

Очистка данных сайта в браузере удалит ответы и практические решения: у сервера и других браузеров их копии нет.

## Экспорт результатов

Markdown-файл UTF-8 формируется полностью в браузере:

- «Скачать результаты урока» — на странице завершения;
- «Скачать результаты темы» — на странице темы;
- «Скачать все результаты» — на главной странице.

В файл включаются названия темы и урока, собственные ответы, признаки фиксации, собственное практическое решение, объяснение, результат запуска, сложности, самопроверка, самооценка и заполненные поля GitHub.

В файл намеренно не включаются полный текст лекции, эталонные ответы, обязательные пункты эталона, подсказки, стартовый код, правильные решения, токены, пароли и посторонние данные `localStorage`.

## JSON API

JSON API сохранён для будущего изучения и развития:

- `GET /health`
- `GET /topics`
- `GET /questions`
- `GET /questions/{id}`
- `POST /reviews`

HTML-интерфейс и API обслуживаются одним Go-приложением. Ошибки API возвращаются в JSON, ошибки HTML-страниц — в HTML с подходящим HTTP status code.

## Первый учебный блок

`stage_01_foundation` включает темы Go Basics, Python Basics, AI/ML Basics и Interview Basics. Материал идёт от базовых понятий к самостоятельным объяснениям и небольшой практике.

## Правило безопасности

Не хранить реальные персональные данные, рабочие данные, чувствительную информацию, токены, пароли и `.env`.

Все примеры, вопросы, ответы и практические данные должны быть нейтральными и учебными.
