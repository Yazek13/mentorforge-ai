# MentorForge AI

Локальная обучающая платформа для подготовки к собеседованиям backend / AI engineer.

Проект помогает изучать Go, Python, SQL, Backend, AI/ML и System Design через уроки, вопросы, ответы, повторения и практические задания.

## Как запустить

```bash
make run
```

## Как запустить тесты

```bash
make test
```

## Endpoint

- `GET /health`
- `GET /topics`
- `GET /questions`
- `GET /questions/{id}`
- `POST /reviews`

## Первый учебный блок

`stage_01_foundation` — базовый блок для старта.

Он включает темы:

- Go Basics
- Python Basics
- AI/ML Basics
- Interview Basics

В этом блоке собраны простые вопросы, короткие ответы, собеседовательные формулировки, примеры реального применения, дополнительные вопросы и маленькие практические задания.

## Правило безопасности

Не хранить реальные персональные данные, рабочие данные, токены, пароли и `.env`.

Все примеры, вопросы и тестовые данные должны быть нейтральными и учебными.
