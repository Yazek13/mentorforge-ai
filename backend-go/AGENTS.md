# AGENTS.md

Этот проект учебный.

Правила для Codex:

1. Писать простой и понятный код.
2. Не добавлять лишние зависимости без явной команды.
3. Не использовать реальные персональные, рабочие или чувствительные данные.
4. Все примеры должны быть нейтральными.
5. После изменений запускать:
   - `gofmt`
   - `go test ./...`
6. Обновлять `README.md`, если меняется поведение проекта.
